# 🤖 AI TRADER

### `AI + Trade + Research`

</div>

**Ask it anything about a stock. Watch it go to work.**

You type a question the way you'd ask a friend who happens to be a quant. It pulls live candles, runs the
indicators, reads the news, checks your portfolio, backtests the idea — then comes back with a real answer and
a chart it drew itself. Entry, target, stop. No dashboard-hunting, no twelve tabs.

It also tells you when the trade is bad. That part was harder to build than the part that says yes.

```
  you  ▸  "is RELIANCE setting up for a breakout today?"
       ▸  agent fetches candles ▸ computes indicators ▸ scans headlines
       ▸  runs the backtest ▸ draws the chart ▸ answers
```

Research-grade underneath: the agent reasons over tools, never over vibes. Every number on screen came from a
deterministic computation, not from a language model doing arithmetic.
